# General Image Preparation

Use this reference when preparing visual panels for a BIM report poster.

## Preparation Process

1. Inspect source images at their available full size.
2. Classify each useful image by its technical role.
3. Select one main image and three to four supporting images.
4. Crop or clean usable images when this is sufficient.
5. Recreate an image only when its quality, interface clutter, or presentation style prevents effective use.
6. Add Chinese titles, labels, dimensions, and callouts later in the editable layout.

## Recreation Principles

- Preserve the source image's project type and technical intent.
- Preserve important visible relationships without claiming engineering accuracy that cannot be verified.
- Aim for clean geometry, readable systems, balanced lighting, and a professional technical-presentation appearance.
- Use a simple, uncluttered background appropriate to the selected image category.
- Avoid fake signs, fake annotations, watermarks, software UI, distorted geometry, unrelated people, and decorative clutter.

## Category Guidance

- Main project image: make the project massing and context easy to recognize.
- MEP or integrated model: keep systems organized and visually distinguishable.
- Local node: focus on one meaningful technical area rather than a random collection of components.
- Structure or civil model: keep structural hierarchy readable.
- Section or clear-height image: preserve the relationship between overhead systems and usable space.
- Point cloud or analysis image: retain the analytical intent while removing irrelevant interface chrome.
- Optimization comparison: make the before/after distinction understandable through composition; place explanatory text in the layout.

## Acceptance Check

Accept an image when:

- its purpose remains clear at card size
- important edges and systems are readable
- it contains no fake text, watermark, or UI bars
- it supports the adjacent caption and project narrative
- it does not make unverifiable technical claims

Choose prompts, model settings, dimensions, refinement steps, and export parameters according to the available tools and source quality.
