# Content Mapping

Use this reference to convert project source material into concise poster modules.

## Extract

Collect verified values for:

- project name
- location
- building area
- function or use
- BIM application points
- project highlights or results
- image titles and captions

Use `待补充` when an important engineering fact is unavailable. Do not create plausible-looking figures and present them as source facts.

## Condense

- Shorten the top title only when necessary; retain the full project name in the overview.
- Convert long BIM descriptions into four to six short bullets.
- Keep one strong sentence for the subtitle or value statement.
- Use one project explanation or key-results module rather than several dense text panels.
- Keep captions short and consistent.

## Select Modules

Choose the right-side module according to the strongest source story:

- 项目说明：background, scope, scanning, point cloud, or operation support
- 关键成果：models, reports, drawings, or deliverables
- 优化成效：before/after improvement, coordination, or collision reduction
- 管控重点：clear height, installation constraints, or risk control
- 施工辅助：site guidance, sequencing, or support details

## Map Images to Cards

- architectural rendering or real scene → 项目效果
- integrated or MEP model → 机电模型 / 综合模型
- civil or structural model → 土建模型
- local detail → 局部节点
- support detail → 支吊架设计
- section or cutaway → 剖面分析
- clear-height image → 净高分析
- optimization comparison → 优化对比
- point cloud → 点云模型
- construction layout → 施工场布

Select one main image and three to four supporting cards. Make the image choices support the written BIM applications.

## Preserve Content During Style Changes

When the user requests only a visual redesign, preserve verified project facts, headings, image roles, module count, and application points unless explicitly instructed otherwise.
