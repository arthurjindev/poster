# Shared BIM Poster Style

Use this reference as a general visual baseline.

## Visual Direction

- Use a clean institutional and engineering-focused style.
- Use blue, white, and pale gray as the main palette.
- Keep the mood formal, precise, and easy to read.
- Avoid cartoon styling, excessive glow, heavy decoration, and oversized marketing composition.

## Baseline Layout

1. Header with organization mark, title, and subtitle.
2. Large main visual.
3. Project overview and BIM application modules.
4. One explanation, results, optimization, or construction-support panel.
5. Three to four supporting image cards.
6. Short footer.

Adapt the arrangement to the source material while retaining a clear reading order.

## Components

- Use deep-blue title bars with clear white text.
- Use white or pale-blue cards with restrained borders.
- Use consistent dimensions for repeated cards.
- Use simple vector icons, arrows, dividers, and technical lines.
- Keep text away from borders and avoid dense paragraphs.
- Keep the organization mark visible and unobstructed.

## Typography

- Make the project title the strongest text element.
- Use clear contrast between titles, labels, values, and captions.
- Use real editable text for all Chinese content.
- Keep body copy concise enough to remain readable at normal viewing distance.

## Images

- Use the main image to establish the project.
- Use supporting cards to demonstrate BIM applications or results.
- Keep labels and dimensions in the layout layer.
- Remove software interface elements and watermarks.
- Use consistent crop behavior across repeated cards.

## Review

- Confirm that facts match the source.
- Confirm that text is readable and editable.
- Confirm that image roles match their captions.
- Confirm that modules align and spacing is consistent.
- Confirm that the poster remains understandable as a thumbnail.

Select exact color values, type scales, grid dimensions, card ratios, decorative geometry, and export settings according to the project and available layout environment.
